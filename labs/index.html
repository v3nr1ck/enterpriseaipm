Companion to the book

Latent Space labs

Six small experiments that make one mechanism visible. None of them is a recipe for shipping a product. If a lab feels small, that is the point.

The six

A and B first. They need a laptop and nothing else. After that, C and D go together, and E and F are independent.

Lab A · 20–30 min · $0

Embeddings

Structure exists in the space without anyone labeling it.

Any laptop, 8GB RAM

Lab B · 30 min · $0

Sampling

There is no decision. There is only a distribution.

Any laptop, 8GB RAM

Lab C · 45–60 min · $0–1

Denoising

Generation is a walk from noise.

6GB VRAM, or rent

Lab D · 45 min · $0–2

Interpolation

The space is continuous and navigable.

6GB VRAM, or rent

Lab E · 45 min · $0

Quantization

Quality is a purchasable dial.

16GB RAM, no GPU

Lab F · an afternoon · $2–5

Fine-tune

Capability has a price measured in examples.

Free Colab, or rent

Total spend if you do all six and use free Colab where offered: under $5.

Start here

The book does not print model names or prices. Those live in CURRENT.md, which is the only file that is allowed to go stale. If a command fails, check that first, then TROUBLESHOOTING.md.

Clone

On your machine

git clone https://github.com/v3nr1ck/enterpriseaipm.git
cd enterpriseaipm/labs/lab-a-embeddings
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python walk_the_space.py

Windows: py -m venv .venv then .\.venv\Scripts\Activate.ps1. Full notes in SETUP.md.

No install

Locked-down laptop

Labs A, B, and F have Colab notebooks. Open the notebook in the lab folder. Nothing installs on your machine.
